# Partner and reviewer calls

Codex is the only shell/git operator. Invoke Claude through Ralph's `partner` command, using the absolute executable path supplied in the orchestrator prompt. Save a complete prompt in a new private file and create a private `calls/` subdirectory, then run `node /absolute/path/to/ralph/dist/cli.js partner --cwd /absolute/worktree --prompt /absolute/run/prompt.md --output /absolute/run/calls/001 --mode read`. The output directory must be new and under this run's git-ignored `.ralph/runs/` directory. For sole edit ownership use `--mode edit`. The command enforces safe mode, empty MCP configuration, read/search tools only for read mode, and read/search/edit/write tools for edit mode. It records a session ID before launch, bounds the call to 900 seconds by default, saves stdout/stderr/metadata, and publishes `response.md` only after a successful JSON result. Use `--model opus --effort medium` unless the user specifies another model. A shell success or `claude auth status` is not enough; quota and API errors can still return JSON. If a call fails, inspect diagnostics and report the blocker without pretending the partner agreed. On resume use only this run's recorded session ID; start diagnosis and simplification fresh. Do not call `claude` directly.

Before the first partner call, inspect `claude --version`, relevant `claude --help` flags, and `claude auth status` privately. If the required safe-mode or tool restriction flags are unavailable, stop with an upgrade requirement. Do not drop isolation flags. In a phase that uses edits, name the permitted files and inspect the before/after changed paths because file scope is a prompt restriction, not a filesystem sandbox. Ensure the partner process has stopped before returning edit ownership or retrying a failed call.

Use `calls/diagnosis` for B's first independent report and copy its successful `response.md` verbatim to `independent_b.md`. Use `calls/simplification` for the fresh simplification session. Ralph verifies both receipts before counting their phases complete. Use separate new call directories for dialogue, adjudication and later turns; record the session IDs in `workflow-state.md`. Never turn an error or partial stdout into a phase report.

For independent diagnosis, give Claude the neutral source packet, repository instructions, and permitted evidence paths. Explicitly forbid reading Codex's report until both reports are saved. Once saved, Claude can read both reports for dialogue. Save each response verbatim as the next even turn. The final status line must be one of `STATUS: OPEN`, `STATUS: RESOLUTION_PROPOSED`, or `STATUS: CONFIRMED`. Codex writes odd turns. B's proposal and A's later confirmation are required for consensus.

For simplification, supply the complete exported diff and literal base/head SHAs. Allow edits only in the agreed scope. While Claude edits, Codex may run check-only commands requested by Claude and return the results. No formatting, autofixes, rebase, commit, or other mutation until Claude has stopped and ownership returns to Codex. Inspect all changed paths before accepting edits.

For review, start fresh read-only Codex sessions, one for each of `review-correctness.md`, `review-compliance.md`, and `review-completeness.md`. Each receives the neutral requirements, instructions, and frozen complete diff, without implementation history. Save outputs separately and verify every finding against source before adjudication. Repeat only correctness after a repair unless the change invalidates other evidence. Do not claim independent review from a resumed implementation session.
